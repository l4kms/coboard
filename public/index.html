Справка CoBoard

  • B кисть, E обычный ластик, X стирание линии
  • F заливка, P пипетка
  • L линия, R прямоугольник, O эллипс, T текст, S выделение
  • Ctrl+Z отменить, Ctrl+Y / Ctrl+Shift+Z повторить
  • Ctrl+V вставить картинку из буфера
  • ПКМ / долгий тап внутри выделения: вырезать / вставить / удалить
  • Пробел + drag = pan; колесо = zoom
  • G сетка, Ctrl+0 сбросить zoom
