# CoBoard 🎨

Совместная онлайн-доска (в стиле MS Paint) с синхронизацией в реальном времени.

## 🚀 Технологии
*   **Backend:** Node.js, Express, Socket.IO
*   **Frontend:** Vanilla JS, HTML5 Canvas
*   **Storage:** Supabase (PostgreSQL)
*   **Hosting:** Render
