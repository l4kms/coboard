# 🎨 CoBoard

**CoBoard** — это совместная онлайн-доска в стиле Microsoft Paint, которая работает в браузере. Рисуйте в одиночку или вместе с друзьями в реальном времени, без установки дополнительного ПО.

🔗 **Демо:** [https://coboard.onrender.com](https://coboard.onrender.com) *(замени на свою ссылку Render)*

---

## ✨ Возможности

- **Инструменты рисования:** Кисть, ластик (обычный и «умный», стирающий линию целиком), линия, прямоугольник, эллипс, заливка, текст, пипетка.
- **Совместная работа:** Мгновенная синхронизация рисунков и курсоров через WebSocket (Socket.IO).
- **Редактирование:** Выделение, перетаскивание, вырезание, копирование, вставка (Ctrl+V), Undo/Redo (Ctrl+Z / Ctrl+Y).
- **Персонализация:** Настройка цвета, толщины кисти и прозрачности.
- **Навигация:** Зум (колесо мыши), панорамирование (пробел + перетаскивание), сетка.
- **Сезонное оформление:** Зимой идёт снег и висит гирлянда, осенью падают листья и т.д.
- **Сохранение:** Автосохранение рисунков в облако (Supabase) и локально. Доска переживает перезапуск сервера и перезагрузку страницы.

---

## 🛠️ Технологический стек

- **Frontend:** HTML5 Canvas, Vanilla JavaScript, CSS3 (без фреймворков).
- **Backend:** Node.js, Express.
- **Связь в реальном времени:** Socket.IO.
- **База данных:** Supabase (PostgreSQL) для хранения состояния комнат.
- **Хостинг:** Render (бесплатный тариф).

## 🚀 Быстрый старт (локально)

### Требования
- Node.js (v18 или выше)
- Git

### Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/l4kms/coboard.git
   cd coboard
2. **Установите зависимости:**
   ```bash
   npm install
3. **Настройте переменные окружения:**
Создайте файл .env в корне проекта и добавьте ключи от вашего проекта Supabase:
   ```bash
   env
   SUPABASE_URL=https://ваш-проект.supabase.co
   SUPABASE_SECRET=ваш-секретный-ключ-service-role
Если вы не хотите подключать Supabase, закомментируйте код в server.js, связанный с базой данных, и используйте локальное сохранение в data/rooms.json.

4. **Запустите сервер:**
   ```bash
   node server.js
   Откройте в браузере:
   Перейдите по адресу http://localhost:3000.

5. **🎮 Горячие клавиши:**
   ```bash
      **Клавиша**	**Действие**
      B	Кисть
      E	Ластик (обычный)
      X	Умный ластик (стирает линию)
      F	Заливка
      P	Пипетка
      L	Линия
      R	Прямоугольник
      O	Эллипс
      T	Текст
      S	Выделение
      Ctrl+Z / Ctrl+Y	Undo / Redo
      Ctrl+V	Вставить из буфера
      Пробел + Drag	Панорамирование
      Ctrl + +/-	Зум
